# WeatherFlow — JavaScript Weather Dashboard

A responsive real-time weather dashboard built using HTML5, CSS3, and modern JavaScript.

The project demonstrates asynchronous JavaScript, REST API integration, JSON processing, dynamic DOM manipulation, and error handling.

---

## Features

- Search weather by city name
- Fetch live weather information
- Uses the JavaScript Fetch API
- Uses async/await
- REST API integration
- JSON response processing
- Dynamic DOM manipulation
- Loading state while fetching data
- Error handling for failed requests
- Invalid city handling
- Responsive design
- Accessible form and status messages
- Displays temperature
- Displays humidity
- Displays wind speed
- Displays weather condition
- Displays weather code
- Displays last updated time

---

## Weather API

This project uses the following public APIs from Open-Meteo:

- Open-Meteo Geocoding API
- Open-Meteo Weather Forecast API

The application first converts the city name into latitude and longitude coordinates and then uses those coordinates to retrieve current weather information.

No API key is required.
